# GS1 EPC Tag Data Translation 2.2 artefacts

The `*.json` files here are the normative machine-readable artefacts of the GS1 EPC Tag Data
Translation (TDT) standard, release 2.2 (artefact date 2024-11-18), for EPC Tag Data Standard
(TDS) 2.2.

Source: https://github.com/gs1/TDT/tree/a655cc35bff6bad4f60b41c4d40d324e4caaef77/artefacts/JSON
(fetched 2026-10-21). Copyright GS1 AISBL, licensed under the Apache License, Version 2.0
(`LICENSE` in this directory).

`scripts/generate-epc-table.mjs` reads them to generate `src/generated/epc-table.ts`. Do not edit
these files by hand; replace them with a newer tagged release instead.
